# SAP 머신 러닝

# 큰 그림

머신 러닝 섹션은 깊은 모델 원리보다 "어떤 AWS AI/ML 서비스를 골라야 하는가"가 시험 포인트다.

```text
이미지/영상 분석
→ Rekognition

음성 → 텍스트
→ Transcribe

텍스트 → 음성
→ Polly

번역
→ Translate

챗봇
→ Lex

콜센터
→ Connect

자연어 이해
→ Comprehend

의료 자연어
→ Comprehend Medical

커스텀 ML 모델 개발/학습/배포
→ SageMaker

시계열 예측
→ Forecast

기업 문서 검색
→ Kendra

개인화 추천
→ Personalize

문서 OCR/양식/표 추출
→ Textract
```

# Rekognition

Rekognition은 이미지와 비디오를 분석한다.

시험 감각:

```text
이미지에서 객체/장면/얼굴 탐지
부적절한 이미지 moderation
얼굴 비교/얼굴 검색
이미지 안의 텍스트 탐지
동영상 분석
→ Amazon Rekognition
```

헷갈리지 않기:

```text
문서 이미지에서 표/양식/필드 추출
→ Textract

사진/영상 안의 사람/객체/장면 분석
→ Rekognition
```

# Transcribe

Transcribe는 음성을 텍스트로 바꾼다.

시험 감각:

```text
고객 통화 녹음 파일을 텍스트로 변환
회의 음성을 자막으로 변환
음성 인식, speech-to-text
→ Amazon Transcribe
```

의료 음성은 Transcribe Medical 쪽 힌트가 나올 수 있다.

# Polly

Polly는 텍스트를 자연스러운 음성으로 읽어준다.

시험 감각:

```text
텍스트를 음성으로 변환
뉴스 기사 읽어주기
음성 안내 생성
text-to-speech
→ Amazon Polly
```

비교:

```text
음성 → 텍스트
→ Transcribe

텍스트 → 음성
→ Polly
```

# Translate

Translate는 텍스트 번역 서비스다.

시험 감각:

```text
다국어 번역
사용자 리뷰/문서/채팅 메시지를 다른 언어로 변환
→ Amazon Translate
```

# Lex와 Connect

Lex는 챗봇/대화형 인터페이스를 만드는 서비스다.
Alexa와 비슷한 대화 엔진을 애플리케이션에 붙이는 감각이다.

```text
챗봇
음성/텍스트 기반 대화
intent / slot 기반 대화 처리
→ Amazon Lex
```

Connect는 클라우드 콜센터 서비스다.

```text
고객센터
전화 상담 라우팅
콜센터 흐름 구성
Lex 챗봇과 연결 가능
→ Amazon Connect
```

시험 감각:

```text
챗봇 자체
→ Lex

콜센터 플랫폼
→ Connect

콜센터에서 챗봇으로 1차 응대
→ Connect + Lex
```

# Comprehend

Comprehend는 자연어 처리 서비스다.
텍스트의 의미를 분석한다.

시험 감각:

```text
감정 분석
핵심 구문 추출
엔티티 인식
언어 감지
주제 모델링
PII 탐지
→ Amazon Comprehend
```

예:

```text
고객 리뷰가 긍정/부정인지 분석
문서에서 사람/장소/회사명 추출
→ Comprehend
```

# Comprehend Medical

Comprehend Medical은 의료 텍스트 전용 NLP다.

시험 감각:

```text
진료 기록
의료 문서
약품, 질환, 검사, 치료 정보 추출
의료 자연어 처리
→ Amazon Comprehend Medical
```

일반 텍스트는 Comprehend, 의료 도메인은 Comprehend Medical로 본다.

# SageMaker

SageMaker는 커스텀 ML 모델을 만들고 학습하고 배포하는 관리형 플랫폼이다.

시험 감각:

```text
데이터 과학자가 직접 모델 개발
학습 job 실행
모델 튜닝
endpoint로 모델 배포
MLOps 파이프라인
→ Amazon SageMaker
```

중요한 구분:

```text
이미 만들어진 AI 기능을 API로 사용
→ Rekognition / Comprehend / Polly 등 AI service

직접 모델을 만들고 학습/배포
→ SageMaker
```

# Forecast

Forecast는 시계열 예측 서비스다.

시험 감각:

```text
미래 수요 예측
재고/판매량/트래픽 예측
시간에 따른 수치 예측
→ Amazon Forecast
```

# Kendra

Kendra는 기업용 지능형 검색 서비스다.
문서 저장소를 연결하고 자연어 질문으로 검색하게 해준다.

시험 감각:

```text
사내 문서 검색
FAQ/위키/문서 저장소를 자연어로 검색
문서 기반 질의응답
→ Amazon Kendra
```

OpenSearch와 헷갈리지 않기:

```text
검색 엔진을 직접 구성하고 로그/문서 인덱싱
→ OpenSearch

관리형 기업 문서 검색, 자연어 질문
→ Kendra
```

# Personalize

Personalize는 개인화 추천 서비스다.

시험 감각:

```text
사용자별 상품 추천
콘텐츠 추천
개인화 랭킹
아마존 쇼핑 같은 추천 기능
→ Amazon Personalize
```

# Textract

Textract는 문서에서 텍스트, 양식, 표를 추출한다.

시험 감각:

```text
스캔 문서 OCR
PDF/이미지에서 텍스트 추출
양식 key-value 추출
표 데이터 추출
→ Amazon Textract
```

Rekognition과 비교:

```text
일반 이미지/영상의 객체와 얼굴 분석
→ Rekognition

문서 이미지에서 텍스트/표/양식 추출
→ Textract
```
